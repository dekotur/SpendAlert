# Code of conduct

## The short version

Be decent. Assume the other person is trying to help.

## Expected behavior

- Keep discussion on the technical problem: what happens, what should happen,
  what the trade-off is.
- Accept that a maintainer of a small self-hosted project has limited time.
  A reproducible report with synthetic data is worth ten "doesn't work" issues.
- Respect the privacy rules in `SECURITY.md` and the issue templates. Posting
  someone else's tokens, chat IDs, database or personal records is a conduct
  problem, not just a mistake.

## Unacceptable behavior

Harassment, personal attacks, discrimination, deliberate derailing, and
publishing private information without consent.

## Scope

Issues, pull requests, discussions, commit messages and code review in this
repository.

## Reporting

Report a conduct problem privately by contacting the maintainer through their
GitHub profile, or via GitHub's own
[abuse reporting](https://github.com/contact/report-abuse) when the situation
warrants platform action. Do not open a public issue about someone's conduct.

Reports are handled on a best-effort basis by a single maintainer. Outcomes may
include editing or deleting content, and blocking an account from the
repository.

This document is a condensed, project-scale adaptation of the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/); it does not
claim to be that document.
